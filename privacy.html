개인정보처리방침 (Privacy Policy)

시행일: 2026년 10월 31일

1. 개요

imsleeping uploader(이하 "도구")는 운영자 1인이 본인 소유의 YouTube 채널에 본인이 제작한 영상을 업로드하기 위해 사용하는 개인용 도구입니다. 일반 사용자에게 서비스로 제공되지 않습니다.

2. 접근하는 Google 사용자 데이터

  • youtube.upload: 운영자 본인 채널에 영상을 업로드하고 제목·설명·썸네일을 설정하는 데만 사용합니다.
  • youtube.readonly: 인증된 계정이 올바른 채널(채널 이름·핸들)인지 확인하는 데만 사용합니다.

3. 데이터 보관

OAuth 인증 토큰은 운영자의 개인 PC에만 저장되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다. YouTube에서 받은 데이터를 별도로 수집·저장·판매하지 않습니다.

4. 제3자 제공

Google 사용자 데이터를 어떤 제3자에게도 제공하거나 판매하지 않으며, 광고 목적으로 사용하지 않습니다. 도구의 Google API 사용은 Google API 서비스 사용자 데이터 정책 (제한적 사용 요구사항 포함)을 준수합니다.

5. 접근 권한 철회

언제든지 Google 계정 → 서드파티 앱 및 서비스에서 이 도구의 접근 권한을 철회할 수 있습니다. 철회 시 PC에 저장된 토큰도 삭제합니다.
